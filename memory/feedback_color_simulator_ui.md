# 混色シミュレータのUIと校正値

- 混色結果は材質球レンダリングでは見づらいため、通常のフラットな色として表示する。
- 操作画面はプロファイル、ベース、染料、結果の順序を明示し、初見でも入力手順が分かるようにする。
- 染料の校正濃度は1.0滴/mLを経験上の初期値とするが、染料によって異なるため各行で編集できるようにする。
- 結果スウォッチを無効化するとBlenderのUIで灰色に減光されるため、計算専用プロパティを有効状態で描画する。
- Hex（sRGB）・sRGB 8-bit・Linear RGBはホバー情報に隠さず常時表示し、値自体をクリックしてコピーできるようにする。
- 白色染料は明示的なWhite Opacifierとして扱う。既定の1.0滴/mLでは半透明ベースも完全不透明・乳白になり、実濃度がそれ未満なら比例して透明度と濁りを変える。
- ベースのTransparencyは「1.0 clear / 0.0 opaque」、Cloudinessは「0.0 clear / 1.0 milky white」と画面内に常時説明する。
