# 混色シミュレータのUIと校正値

- 混色結果は材質球レンダリングでは見づらいため、通常のフラットな色として表示する。
- 操作画面はプロファイル、ベース、染料、結果の順序を明示し、初見でも入力手順が分かるようにする。
- 染料の校正濃度は1.0滴/mLを経験上の初期値とするが、染料によって異なるため各行で編集できるようにする。
- 結果スウォッチを無効化するとBlenderのUIで灰色に減光されるため、計算専用プロパティを有効状態で描画する。
- Hex（sRGB）・sRGB 8-bit・Linear RGBはホバー情報に隠さず常時表示し、値自体をクリックしてコピーできるようにする。
- 全染料が透明度を下げ、既定では染料合計1.0滴/mL程度で不透明になる。白色染料はそれに加えて他の染料色を白の校正色へ薄める。
- 染料色はHSLの彩度を常に100%へ固定し、BlenderのカラーピッカーではなくHue（度）とLightness（%）で入力する。Lightnessは固定せず、茶色などの暗い染料も表現する。
- Lightness 100%は白として自動的に他色を淡くし、0%の黒とそれ以外の色は自動的に減法混色へ入れて暗くする。白指定用チェックボックスは使わない。
- 光学設定はTransparency（1.0 clear / 0.0 opaque）だけを扱い、Cloudinessは表示・計算しない。
- 操作Tipsは色指定と染料別校正の2行程度に絞り、説明を重複させない。
